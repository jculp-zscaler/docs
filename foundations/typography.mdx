## Weights

| Weight  | Value | Use for                                        |
| :------ | :---- | :--------------------------------------------- |
| Regular | 400   | Body copy, captions, table cells               |
| Medium  | 500   | Component labels, buttons, small headings      |
| Bold    | 700   | Page and section headings, display text        |

## Rules

- Line length: 45–75 characters for body copy.
- Never use font size alone to establish hierarchy — pair it with weight or color.
- Numbers in tables use tabular figures (`font-variant-numeric: tabular-nums`).
- Minimum text size is 12px; prefer 14px for anything users must read to act.
