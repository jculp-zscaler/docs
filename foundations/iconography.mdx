## Sizes

| Size | Use for                                |
| :--- | :------------------------------------- |
| 16px | Inline with body text, table cells     |
| 20px | Buttons, form fields, navigation       |
| 24px | Page headers, empty states, feature tiles |

## Rules

- Icons are always paired with text or an `aria-label` — never a bare icon button without a name.
- Decorative icons set `aria-hidden="true"`.
- Keep the 2px stroke; don't scale icons by changing stroke weight.
- Use the outline style everywhere; filled variants are reserved for active navigation states.
