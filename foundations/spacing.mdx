## How to choose a step

| Range              | Use for                                            |
| :----------------- | :------------------------------------------------- |
| `space-1` – `space-3` | Inside components: icon gaps, label spacing     |
| `space-4` – `space-6` | Between related elements: form fields, card padding |
| `space-7` – `space-10`| Between sections: page regions, empty-state padding |

## Rules

- Vertical rhythm between form fields is `space-5` (20px).
- Card and modal padding is `space-5`; dense tables may drop to `space-3`.
- Section spacing on marketing-style pages starts at `space-9`.
- Never introduce off-scale values — request a new step through the [contribution process](/resources/contribution-process) instead.
