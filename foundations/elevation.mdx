## When to use each level

| Level | Token            | Use for                                   |
| :---- | :--------------- | :---------------------------------------- |
| 1     | `--zds-shadow-1` | Resting cards, inputs, table rows         |
| 2     | `--zds-shadow-2` | Dropdowns, tooltips, hover states         |
| 3     | `--zds-shadow-3` | Popovers, hovering interactive cards      |
| 4     | `--zds-shadow-4` | Modals, command palettes — one per screen |

## Rules

- Elevation communicates **stacking order**, not importance. Use color and type for emphasis.
- Never combine two level-4 surfaces — if a modal needs a modal, the flow needs a redesign.
- Elevation changes animate with `--zds-duration` / `--zds-ease` and respect `prefers-reduced-motion`.
