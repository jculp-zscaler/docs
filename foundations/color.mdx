## Contrast rules

| Pairing | Minimum ratio | Where it applies |
| :-- | :-- | :-- |
| Body text on any background | 4.5:1 | All text under 18px |
| Large text (≥ 18px medium) | 3:1 | Headings, hero copy |
| UI component boundaries | 3:1 | Input borders, focus rings, icons |

Use `blue-500` and up for text on light backgrounds; `blue-300` and lighter for text on dark backgrounds. Status colors at the `500` step pass 4.5:1 on white; the `100` steps are backgrounds only.
