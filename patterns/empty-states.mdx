## Anatomy

An empty state has exactly four parts, top to bottom: an icon, a one-line headline, one sentence of context, and a single primary action.

## Rules

- **Headline states the fact** ("No forwarding rules yet"), never blames ("You haven't created any rules").
- **Context sells the value** of the first item, in one sentence.
- **One action only.** If there are two ways to get started, pick the one that succeeds most often.
- Use a 32px [icon](/foundations/iconography), never an illustration — illustrations aren't themable.

## Variants

| Situation           | Difference                                                                 |
| :------------------ | :------------------------------------------------------------------------- |
| First run           | The pattern above.                                                          |
| Empty search result | Headline echoes the query; action clears filters. No primary button.       |
| Error loading       | Use an [Alert](/components/alert) with `severity="danger"` instead — an error is not an empty state. |
| Permission gated    | Say who can add content; action becomes "Request access".                  |
