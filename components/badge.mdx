## Props

| Prop       | Type                                                                       | Default     | Description                                 |
| :--------- | :------------------------------------------------------------------------- | :---------- | :------------------------------------------ |
| `tone`     | `"neutral" \| "brand" \| "success" \| "warning" \| "danger" \| "outline"` | `"neutral"` | Semantic color of the badge.                |
| `dot`      | `boolean`                                                                   | `false`     | Shows a leading status dot.                 |
| `children` | `ReactNode`                                                                 | —           | Badge text. One or two words.               |

## Accessibility

<AccordionGroup>
  <Accordion title="Semantics" icon="accessibility">
    - Badges are static `<span>` elements — they receive no focus and no pointer affordance.
    - Color is never the only signal: the badge text carries the state on its own.
    - All tone combinations meet a 4.5:1 contrast ratio in light and dark themes.
  </Accordion>
</AccordionGroup>
