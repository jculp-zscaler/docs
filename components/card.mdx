## Props

| Prop          | Type        | Default | Description                                          |
| :------------ | :---------- | :------ | :--------------------------------------------------- |
| `title`       | `string`    | —       | Card heading.                                        |
| `media`       | `ReactNode` | —       | Optional media slot rendered above the body.         |
| `interactive` | `boolean`   | `false` | Adds hover lift; the whole card becomes a click target. |
| `elevated`    | `boolean`   | `false` | Borderless style with a level-3 shadow.              |
| `children`    | `ReactNode` | —       | Body content and optional `Card.Footer`.             |

## Accessibility

<AccordionGroup>
  <Accordion title="Semantics" icon="accessibility">
    - Interactive cards render as a single `<a>` element; inner actions are not focusable separately.
    - The card title is a heading element, keeping the page outline intact.
    - Hover lift uses `transform` only — it respects `prefers-reduced-motion`.
  </Accordion>
</AccordionGroup>
