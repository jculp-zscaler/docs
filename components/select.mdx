  <label class="zds-field__label" for="region">Region</label>

  </select>

## Props

| Prop       | Type      | Default | Description                                             |
| :--------- | :-------- | :------ | :------------------------------------------------------ |
| `label`    | `string`  | —       | Visible label. Required.                                |
| `error`    | `string`  | —       | Error message; replaces the hint and styles the border. |
| `required` | `boolean` | `false` | Marks the label and sets `aria-required`.               |
| `disabled` | `boolean` | `false` | Prevents interaction.                                   |
| `children` | `ReactNode` | —     | `Select.Option` elements.                               |

## Accessibility

<AccordionGroup>
  <Accordion title="Semantics" icon="accessibility">
    - Renders a native `<select>` — full keyboard and screen-reader support with zero custom ARIA.
    - The chevron affordance is a background image and stays out of the accessibility tree.
    - Native behavior on mobile: the OS option picker opens, not a custom dropdown.
  </Accordion>
</AccordionGroup>
