```jsx React
import { Input } from "@zenith/ui";

<Input
  label="Tunnel name"
  placeholder="e.g. hq-primary-gre"
  hint="Lowercase letters, numbers, and hyphens only."
  required
/>
```

```html HTML
<div class="zds-field">
  <label class="zds-field__label zds-field__label--required" for="tunnel">Tunnel name</label>
  <input class="zds-input" id="tunnel" placeholder="e.g. hq-primary-gre" />
  <span class="zds-field__hint">Lowercase letters, numbers, and hyphens only.</span>
</div>
```

## Props

| Prop          | Type      | Default | Description                                             |
| :------------ | :-------- | :------ | :------------------------------------------------------ |
| `label`       | `string`  | —       | Visible label. Required — never rely on placeholder text. |
| `placeholder` | `string`  | —       | Example value, not instructions.                        |
| `hint`        | `string`  | —       | Persistent helper text below the field.                 |
| `error`       | `string`  | —       | Error message; replaces the hint and styles the border. |
| `required`    | `boolean` | `false` | Marks the label with an asterisk and sets `aria-required`. |
| `disabled`    | `boolean` | `false` | Prevents editing.                                       |

## Accessibility

<AccordionGroup>
  <Accordion title="Labeling and errors" icon="accessibility">
    - The label is programmatically associated via `for`/`id`.
    - Error messages are linked with `aria-describedby` and the field sets `aria-invalid="true"`.
    - Error styling changes the border **and** shows a message — color is never the only signal.
  </Accordion>
</AccordionGroup>
