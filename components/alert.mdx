## Props

| Prop       | Type                                              | Default  | Description                                        |
| :--------- | :------------------------------------------------ | :------- | :------------------------------------------------- |
| `severity` | `"info" \| "success" \| "warning" \| "danger"`   | `"info"` | Semantic severity; sets the icon and accent color. |
| `title`    | `string`                                          | —        | One-line summary. Required.                        |
| `tinted`   | `boolean`                                         | `false`  | Fills the background with the severity subtle color. |
| `children` | `ReactNode`                                       | —        | Supporting detail. One or two sentences.           |

## Accessibility

<AccordionGroup>
  <Accordion title="Semantics" icon="accessibility">
    - Alerts rendered in response to a state change use `role="alert"` so screen readers announce them.
    - Alerts present at page load use `role="status"` instead, to avoid duplicate announcements.
    - The severity icon is `aria-hidden`; the title text carries the meaning.
  </Accordion>
</AccordionGroup>
