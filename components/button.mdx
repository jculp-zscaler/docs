## Props

| Prop       | Type                                              | Default     | Description                                              |
| :--------- | :------------------------------------------------ | :---------- | :------------------------------------------------------- |
| `variant`  | `"primary" \| "secondary" \| "ghost" \| "danger"` | `"primary"` | Visual emphasis of the button.                            |
| `size`     | `"sm" \| "md" \| "lg"`                             | `"md"`      | Height and padding scale.                                 |
| `disabled` | `boolean`                                          | `false`     | Prevents interaction and reduces opacity.                 |
| `loading`  | `boolean`                                          | `false`     | Replaces the label with a spinner and blocks interaction. |
| `children` | `ReactNode`                                        | —           | Button label. Keep it to a verb phrase.                   |

## Accessibility

<AccordionGroup>
  <Accordion title="Keyboard interaction" icon="keyboard">
    | Key               | Behavior                                        |
    | :---------------- | :---------------------------------------------- |
    | <kbd>Tab</kbd>    | Moves focus to the button.                      |
    | <kbd>Enter</kbd>  | Activates the button.                           |
    | <kbd>Space</kbd>  | Activates the button.                           |

    Focus styles use a 3px ring at 3:1 contrast against adjacent colors.
  </Accordion>
  <Accordion title="ARIA and semantics" icon="accessibility">
    - Renders a native `<button>` element — no ARIA role patching required.
    - The `loading` state sets `aria-busy="true"` and keeps the accessible name stable while the label is visually replaced.
    - Icon-only buttons require an `aria-label`. The sandbox above accepts text labels only.
  </Accordion>
</AccordionGroup>

## Design tokens

The Button consumes these tokens. Change them once in [design tokens](/foundations/design-tokens) and every button updates.

| Token                        | Role                          |
| :--------------------------- | :---------------------------- |
| `--zds-color-primary`        | Primary background            |
| `--zds-color-primary-hover`  | Primary hover background      |
| `--zds-color-danger`         | Danger background             |
| `--zds-radius-sm`            | Corner radius (`sm`/`md`)     |
| `--zds-radius-md`            | Corner radius (`lg`)          |
| `--zds-focus-ring`           | Focus indicator               |
