## Props

| Prop       | Type              | Default | Description                                  |
| :--------- | :---------------- | :------ | :------------------------------------------- |
| `checked`  | `boolean`         | —       | Controlled on/off state.                     |
| `onChange` | `(next: boolean)` | —       | Called with the next state.                  |
| `size`     | `"md" \| "sm"`    | `"md"`  | Track size. Use `sm` in dense tables.        |
| `disabled` | `boolean`         | `false` | Prevents interaction.                        |
| `children` | `ReactNode`       | —       | Visible label. Required.                     |

## Accessibility

<AccordionGroup>
  <Accordion title="Keyboard and semantics" icon="accessibility">
    | Key              | Behavior                    |
    | :--------------- | :-------------------------- |
    | <kbd>Tab</kbd>   | Moves focus to the toggle.  |
    | <kbd>Space</kbd> | Flips the state.            |

    - Built on a native checkbox with `role="switch"` semantics from the label association.
    - The focus ring renders on the visible track, not the hidden input.
  </Accordion>
</AccordionGroup>
