## Principles

1. **Semantic over literal.** Components consume meaning (`--zds-color-danger`), never raw values. That's why dark mode is free.
2. **Accessible by default.** Every stable component meets WCAG 2.2 AA. Accessibility is a release gate, not a follow-up.
3. **Live documentation.** If the docs show a component, it's the production component running — not a screenshot that can drift.
4. **One way to do it.** When two components can solve the same problem, the docs say which one to use and when.
